# Brief: where our customer data comes from (a second design)

Marketing keeps asking where our customer data comes from. The CRM, web analytics, the
billing system and support tickets feed the lakehouse; the data is cleaned in three stages
(raw, cleaned, business-ready) and ends up in the Power BI dashboards marketing uses and in
the churn model. Explain it to the marketing team.

The same brief as [data-lineage](../data-lineage/brief.md). Here one agent wrote the design
down (the point, the form, what each visual variable carries) and another agent built the
figure from that note alone.
