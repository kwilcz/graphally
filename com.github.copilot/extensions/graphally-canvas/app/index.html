Layers

    Keys and gestures
    Click
    select what moves as a whole; again, one level in
    Shift+click
    add to the selection, or take away; then Delete or Ctrl+G
    Drag
    move it within its layout: another cell, place or group; past a grid's edge, a new column or row
    Ctrl-drag
    into any container: each one is outlined
    Alt-drag
    nudge it, snapping to other boxes (Ctrl+Alt: no snapping)
    Corner dot
    drag it to another box to draw a line
    Edge squares
    drag them to change a grid span
    Double-click
    edit the text, or a line's label
    ↑ ↓ ← →
    sibling before, after; parent; first child
    Alt + arrows
    move before, after; out of the parent, into the sibling before
    Enter, Delete
    edit the text; delete (a box with its lines)
    Ctrl+D, Ctrl+G
    duplicate; group (Ctrl+Shift+G ungroups)
    Ctrl+Z, Ctrl+Y
    undo, redo
    Ctrl+= / −
    zoom in, out; Shift+1 fits, Shift+0 is 100%; Ctrl+wheel zooms
    Esc, ?
    select the parent, or stop connecting; fold this help
