# Infographic or slide

graphally draws this; this skill routes to it.

1. Load the graphally skill and follow its workflow. Where skills are not loaded by name, read
   `../graphally/SKILL.md` beside this folder; its scripts are in `../graphally/scripts/`.
2. Before designing, read graphally's `references/design.md` (the method and the standard),
   `references/infographics.md` (formats and sizes), `references/fonts.md` (choosing type), the
   reference for the figure's kind when it has one (`network.md` for a network, `process.md` for
   a process: graphally's table), and `references/icons.md` when the client has icons of its own.
3. Draw what the user typed with the command or described in the conversation. When the facts,
   their sources or the format (a 16:9 slide, a one-pager, a printed page, a social image) are
   missing, ask for them first; when there is no one to ask, choose the format the use suggests
   and say which you assumed.

If graphally is not installed, say so and give the install steps at
https://github.com/kwilcz/graphally#install-for-your-agent; do not draw it another way.
